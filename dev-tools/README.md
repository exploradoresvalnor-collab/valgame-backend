# Dev Tools - Scripts y Herramientas de Desarrollo

Esta carpeta contiene scripts temporales, herramientas de desarrollo y archivos de testing que se han movido desde la raíz del proyecto para mantener el workspace organizado.

## Contenido

### Scripts de Mantenimiento y Limpieza
- `cleanup-docs-folder.sh` - Script para limpiar carpeta de docs
- `cleanup-old-docs.sh` - Limpieza de documentación antigua
- `delete-old-docs.sh` - Eliminación de docs obsoletos
- `execute-cleanup.sh` - Ejecutor de limpieza
- `final-cleanup.sh` - Limpieza final
- `git-consolidate.sh` - Consolidación de git

### Scripts de Testing
- `MEGA_TEST.sh` - Suite de tests completa
- `test-endpoints.sh` - Testing de endpoints
- `PASOS_FINALES.sh` - Pasos finales de testing

### Scripts de Ejecución
- `EJECUTAR_CONSOLIDACION.sh` - Script de consolidación general

### Logs y Debug
- `dev-server.log` - Log del servidor de desarrollo
- `.test_output_userpackage.log` - Output de tests de user packages
- `jest-store-verbose.log` - Log detallado de tests de store
- `bash.exe.stackdump` - Dump de stack de bash (debug)

## Notas
- Estos archivos se movieron desde la raíz para mantener el proyecto organizado
- Algunos pueden ser útiles para desarrollo futuro o debugging
- Se pueden eliminar si ya no son necesarios después de verificar que no contienen información importante
